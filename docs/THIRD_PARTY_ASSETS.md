# 素材・依存の記録

確認日: 2026-10-22。

| 対象 | 入手元・作者 | ライセンス・扱い |
|---|---|---|
| ゴキブリの低ポリ球・棒メッシュ | 本プロジェクトのC#生成コード | 外部3D素材なし |
| キッチンの形状 | Unity標準Primitive＋本プロジェクトの配置コード | Unity利用条件に従う。外部有料アセットなし |
| マテリアル | 本プロジェクトのコード生成色 | 外部テクスチャなし |
| シェーダー | Unity標準Standard | Unity同梱。独自購入なし |
| 日本語フォント | 実行先WindowsのYu Gothic / Meiryo | OSのインストール済みフォントを実行時に参照。フォントファイルは複製・再配布していない。今後同梱する場合は別途ライセンス確認 |
| DesignReferences PNG6枚 | ユーザー提供の既存資料 | デザイン参照のみ。3Dモデルやゲーム背景として使用していない。元画像の配布権利は今回新たに確認していない |
| Unity標準モジュール | Editor 6000.0.61f1 同梱 | Packages/manifest.json、packages-lock.json参照。外部パッケージ導入なし |

音声・BGM・外部フォント・有料API・有料AI 3D生成・Blender依存は今回追加していない。

## 2026-10-23 Blenderモデル改善版の追記

上記は初期Phase1/2時点の記録。今回のユーザー依頼により、制作ツールとしてインストール済みのBlender 5.2.1を使用した。

| 対象 | 入手元・作者 | 扱い |
|---|---|---|
| ゴキブリ・住人のメッシュ、リグ、3段階LOD | 本プロジェクトの `Tools/Blender/build_character_models.py` でBlender上に制作 | 外部モデル・購入素材なし。編集可能な.blendとFBXをArtSourceに保存 |
| 表面の色・滑らかさ | 本プロジェクトの頂点カラー | 外部テクスチャ・画像生成APIなし |
| VertexSurface.shader | 本プロジェクトの独自シェーダー、Unity標準Surface Shader機構を使用 | 追加パッケージなし |
| Blender | PCにインストール済みの5.2.1 | 制作・再生成時に使用。実行ファイルに同梱せず、ゲーム起動時の依存なし |

既存資料画像からテクスチャを切り出したり、外部人物モデルを流用したりしていない。
