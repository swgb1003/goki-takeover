### 2階建ての作り方（`Scripts/Stage/FloorLinks.cs`）
2Fは1Fの真上ではなく、同じ高さ（床 y=0）の離れた場所（x 44〜）にある。これまでの「床にいるか（y < 0.5）」の判定・仲間の床グリッド・人間のNavMeshをそのまま使えるため。
- **主人公**: 客席の階段を登りきる（見えないスロープで普通に歩いて登れる）と、画面が一瞬暗くなって2Fの降り口の横に出る。2Fの降り口へ進むと1Fの階段の下に出る。厨房の壁の下の金網（ダクト、1.3×1.1）に入ると2Fの休憩室のダクトから出る（逆も）。暗い間は動けない。着いた場所は入口の外なので、すぐ戻されることはない。
- **仲間**: 床グリッドに「つなぎ」（階段・ダクトの両端）を足し、経路探索がつなぎを通れるようにした（`AllyNavGrid.SetLinks`・`LinkJump`）。つなぎの端に着くと反対側に出る。つなぎがない旧グリッドでは従来どおり。
- **人間**: 階段は NavMesh のリンク。人間がリンクに乗ると、階段を登って（2Fでは穴へ下りて）見えなくなり、反対の階で現れて歩き出す（`IFloorTraveller`、`HumanAIController.Floors`。既定はnullで従来どおり）。ダクトは人間は通らない。
- HUD: 左上の「STAGE 3 / 町中華」の後ろに今いる階（1F・2F）。階段・ダクトの近くで「階段を登ると 2F へ」「ダクトに入ると 2F へ（ゴキブリだけの道）」。

### テストで見つけて直した不具合
- 階段の段差（0.42）を主人公が「壁」として登ろうとする → 段の上に見えないスロープを置いた（人間のNavMeshからは外す）。
- 2Fの降り口で、暗転中も主人公が歩き続けて穴の底へ落ち、落下の巻き戻しが3回起きた → 暗転中は動けないようにした（FloorLinks をセッションの後・移動の前に実行）。
- ダクトの入口（0.9×0.7）が主人公（半径約0.47）より小さく入れなかった → 1.3×1.1に広げた。
- 家具のちらつき（同じ面で重なる板）: 入口の枠・段の鼻先・階段の上の囲い・スチール棚・2Fの穴の壁・ソファの背を修正。
- 目視: 2Fにいるのに1Fの区域・巣の表示（「流し台の前」など）が壁越しに見えた（2Fは1Fの横にあるため）→ カメラと違う階の表示は出さないようにした。
- 目視: 宴会座敷の奥（階段の穴の側）の壁が暗すぎた → 補助の照明を追加。

### 攻撃（すべて橙の予告つき、床の予告は y 0.045）
- **熱湯流し**（`HotWaterAttack`）: 床のゴキブリが 2〜5m にいると、足元から 5.6×1.1 の橙の帯で予告（1.1秒）→ 熱湯が帯を流れ（0.5秒）、1.6秒そこにたまる。帯の上の主人公はダメージ1、仲間はスリッパと同じ（1回目はひっくり返る）。帯から横へ出ればよい。間隔9秒。
- **お盆**（`HumanAIController.ConfigureWeapon`）: スリッパと同じ流れで叩くが、当たる範囲が横長の四角（幅2.6・奥行1.0）。予告も四角（`RectTelegraph`）。前後へ逃げる。
- **アルコールスプレー**（`AlcoholSprayAttack`）: 2.2〜4.6m で、掃除機と同じ形の橙の扇で予告（0.8秒）→ 白い霧（1.4秒）。浴びると4秒間、移動が半分（`PhaseTwoSession.SlowDown`、仲間は `AllyRoach.SlowUntil`）。ダメージはない。
- **デッキブラシ**（`DeckBrushAttack`）: 2.8m 以内で目の前に 3.2×1.6 の橙の四角（0.9秒）→ 一気に掃く。中の主人公はダメージ1で掃き飛ばされる（約2m）、仲間はひっくり返って飛ばされる。
- **モップがけ**（`MopDuty`・`WetFloor`）: 平穏な時、26秒ごとに12秒間、巡回しながら床を拭き、歩いた跡に濡れた床（半径0.85、青く光る輪）を残す。30秒で乾く。濡れた床の上では足がすべり（`RoachMotor.Traction`）、手を離しても進み続け、曲がりにくい。仲間はすべらない。

## タイトル画面の作り替え（2026-10-26、ユーザー指示・案2b）
UI/UX改善案のキャンバス（案2b「なじませ版」）のうち、タイトル画面だけを先に実装した。左下の「潜入・繁殖・軍団侵略」の3つはユーザー指示で削除。
- 見た目（`Scripts/UI/PaperKit.cs` 新規、`TitleMenu.TitlePage`）: メニューは右の縁からはみ出す段ボールの切れ端に、「はじめる」は黄緑の丸いシール、ほかは紙テープ。サブタイトルは破れた紙テープの上。右上はキーの形の「↑↓ えらぶ / Enter 決定」。素材はすべてコードで1回だけ描いてキャッシュする（画像アセットなし、キャンバスの2倍の解像度でミップマップ付き）。
- なじませ: 影はくっきりした影でなく真下へのぼかし影。画面全体（場面とUI）に同じ暖色・周辺減光・粒子を重ねる（`PaperKit.Grade`）。ロゴは今の形と色のまま。
- 選択: 赤ペンの丸が選んだ項目へ0.18秒で移動し、小さなゴキブリが進む向きを向いて後を追う。マウスを載せても選択が移る。
- 決定（押した感）: 紙が押されて0.9倍に縮み、少し跳ね返って元に戻る（0.32秒）。赤ペンがもう一周して二重丸になり、ゴキブリが項目へ飛びつく。画面の切り替えはこの動きのあと（0.26秒）。記録がない時の「つづきから」は首を振るように左右に揺れて、橙のガムテープで「記録がありません」を出す。
- つづきからのテープに、記録のステージと日時（MM/dd HH:mm）を出す。
- テスト（ステージ3検証版プレイヤーに3項目追加、65→68）: 記録なしの「つづきから」は進まない、押した直後はタイトルのまま、押す動きのあとで「設定」が開く。目視用に [選択中](Validation/Phase5/stage3/player/title-focus-720p.png)・[押した瞬間](Validation/Phase5/stage3/player/title-press-720p.png)。
