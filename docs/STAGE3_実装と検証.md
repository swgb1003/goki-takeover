### 2階建ての作り方（`Scripts/Stage/FloorLinks.cs`）
2Fは1Fの真上ではなく、同じ高さ（床 y=0）の離れた場所（x 44〜）にある。これまでの「床にいるか（y < 0.5）」の判定・仲間の床グリッド・人間のNavMeshをそのまま使えるため。
- **主人公**: 客席の階段を登りきる（見えないスロープで普通に歩いて登れる）と、画面が一瞬暗くなって2Fの降り口の横に出る。2Fの降り口へ進むと1Fの階段の下に出る。厨房の壁の下の金網（ダクト、1.3×1.1）に入ると2Fの休憩室のダクトから出る（逆も）。暗い間は動けない。着いた場所は入口の外なので、すぐ戻されることはない。
- **仲間**: 床グリッドに「つなぎ」（階段・ダクトの両端）を足し、経路探索がつなぎを通れるようにした（`AllyNavGrid.SetLinks`・`LinkJump`）。つなぎの端に着くと反対側に出る。つなぎがない旧グリッドでは従来どおり。
- **人間**: 階段は NavMesh のリンク。人間がリンクに乗ると、階段を登って（2Fでは穴へ下りて）見えなくなり、反対の階で現れて歩き出す（`IFloorTraveller`、`HumanAIController.Floors`。既定はnullで従来どおり）。ダクトは人間は通らない。
- HUD: 左上の「STAGE 3 / 町中華」の後ろに今いる階（1F・2F）。階段・ダクトの近くで「階段を登ると 2F へ」「ダクトに入ると 2F へ（ゴキブリだけの道）」。

### テストで見つけて直した不具合
- 階段の段差（0.42）を主人公が「壁」として登ろうとする → 段の上に見えないスロープを置いた（人間のNavMeshからは外す）。
- 2Fの降り口で、暗転中も主人公が歩き続けて穴の底へ落ち、落下の巻き戻しが3回起きた → 暗転中は動けないようにした（FloorLinks をセッションの後・移動の前に実行）。
- ダクトの入口（0.9×0.7）が主人公（半径約0.47）より小さく入れなかった → 1.3×1.1に広げた。
- 家具のちらつき（同じ面で重なる板）: 入口の枠・段の鼻先・階段の上の囲い・スチール棚・2Fの穴の壁・ソファの背を修正。
- 目視: 2Fにいるのに1Fの区域・巣の表示（「流し台の前」など）が壁越しに見えた（2Fは1Fの横にあるため）→ カメラと違う階の表示は出さないようにした。
- 目視: 宴会座敷の奥（階段の穴の側）の壁が暗すぎた → 補助の照明を追加。
