## ここからコピー

あなたはUnity/C#によるPCゲーム開発のシニアエンジニアです。
このプロジェクトで **GOKI TAKEOVER（ゴキブリ侵略サバイバル）** を段階的に実装します。

まず `Docs/GOKI_TAKEOVER_統合開発仕様書_v1.0.md` を全文読み、実装方針と各フェーズの受け入れ条件を確認してください。参照パスが違う場合はプロジェクト内の同名ファイルを探してください。6枚のPNGはUI・世界観の参考画像であって3Dモデルデータではありません。

### 絶対条件

- 開発環境はWindowsノート、RAM 16GB、Intel UHD Graphics。軽量ローポリ3Dを第一優先。Windowsビルド1280×720／30fps以上を**目標として後で実測**する。実測前に達成したとは言わない。
- ゴキブリのモデルはUnity標準のPrimitiveとC#で生成する。Blenderを必須とせず、有料アセット・有料AI 3D生成サービス・有料APIを導入しない。
- 日本語UI。三人称＋見下ろし軍団モード（Tab切替）が**最終目標**。ただし今は最初のフェーズだけ開発する。
- 既存シーン、アセット、設定を無断で削除・置換しない。必要な変更は差分を明記する。
- 専用の `Assets/_GokiTakeover/` 配下で実装を進める（既存構成があれば安全に合わせる）。
- Unity Editorが利用できない実行環境なら、コードの作成と実際のUnity動作テストを明確に区別する。

### まず実行すること（Phase 0）

1. 現在のUnityプロジェクト構成、Unityバージョン、Render Pipeline、入力方式、導入パッケージ、シーンとGit状態を調査する。
2. 既存コードやアセットとの衝突・既存プロジェクト破壊リスクを洗い出す。
3. 最小の実装構成、必要ファイル一覧、進め方を簡潔に示す。
4. 原則として追加依存を入れず、開発を開始する。

### 今回の実装範囲（Phase 1のみ）

**A. 無料3Dゴキブリの自動生成**
- Unity Editorメニュー `Tools > GOKI TAKEOVER > Generate Cockroach` を追加。
- ブラウンの楕円状胴体、頭、甲殻（左右2枚）、大きすぎない目2個、6本の節付き脚、長い触角2本を生成。
- 全パーツを整理した親子Transform構造にする。プレハブ保存、再生成時の重複防止、色・大きさ調整用SerializeFieldを実装。
- メッシュとマテリアルを極力再利用し、Intel UHD Graphics向けに軽量化。

**B. アニメーションと操作**
- Idle：触角がゆっくり動く。
- Walk / Run：左右交互の3点支持に見える簡易脚動作。走ると歩行周期が速くなる。
- WASD移動、Shiftダッシュ、マウス視点回転の三人称操作。
- 床や家具にめり込まない基本的な当たり判定とカメラ追従。

**C. 軽量試験ステージ**
- 床、壁、机、椅子、冷蔵庫、棚をPrimitive中心に構築したキッチン1部屋。
- 720pで見やすい仮HUD：HP、FPS、操作方法。
- 人間や食料は今回は目印だけでよい。人間AI、食料納品、繁殖、巣の詳細、壁登り、軍団AI、全画面UIは今は実装しない。

### 品質・安全条件

- Editor専用APIはEditorフォルダへ置き、Runtimeと混ぜない。
- 生成したキャラとキッチンを再現できるメニュー・手順を必ず用意する。
- デフォルトシーンを破壊せず、専用テストシーンを用意する。
- null参照やPrefab未設定で実行時に落ちないよう、参照チェックとわかりやすいログを入れる。
- 処理負荷を下げるため、不要なオブジェクト生成・物理処理・毎フレームの重い探索を避ける。
- 仕様に反する変更は理由と代替案を明記し、独断で機能を削除しない。

## 実行後にユーザーが確認すること

- Unityで専用のテストシーンを開く。
- `Tools > GOKI TAKEOVER > Generate Cockroach` が存在する。
- ゴキブリが生成され、再生時にIdle・Walk・Runで脚と触角が動く。
- WASDで移動、Shiftでダッシュ、マウスで視点操作できる。
- 机・壁に突き抜けない。
- Unity Consoleに新たな赤いコンパイルエラーがない。
- Windowsビルドが作れる場合は1280×720で実測し、30fpsの目標との差を記録する。

確認が終わってから、次にPhase 2（食料回収、人間1体、逃走、トラップ）へ進みます。
