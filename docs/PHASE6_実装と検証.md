## 動作確認の手順

1. `Build/GokiTakeover_v1.0/GokiTakeover.exe` を起動（同じフォルダの `遊び方.txt` に操作説明）。
2. タイトルで ↑↓ と Enter（選択音・決定音）→ ステージ選択 → 出撃。
3. 初回はチュートリアルに従う。食料を拾う・納品・繁殖・占拠でそれぞれ効果音が鳴る。人間に見つかる・スリッパ・燻煙剤でも鳴る。
4. Esc → 設定 → 音量を変えると効果音全体の大きさが変わる。

## 追加調整（2026-10-24 夜2）: 仲間の一撃死対策・F呼び戻し・人間の図鑑・駆除業者モデル

- **ひっくり返り（A）**: 1回目のスリッパでは仲間は死なず、2秒ひっくり返って足をばたつかせる（`AllyRoach.Hit`、状態 `Stunned`）。傷が残っている間（巣に入るか30秒で治る）にもう一度叩かれるとやられる。「仲間がひっくり返った！」と通知し、地図に「! ひっくり返り」を表示。調整値は `StageDefinition.allyStunSeconds`（2）・`allyWoundHealSeconds`（30）。
