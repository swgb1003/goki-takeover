# ステージ2「一軒家」 実装と検証（2026-10-25）

ステージ1「ワンルームのキッチン」をクリアすると出撃できる2つ目のステージ。仕様書 9.1 の「4人家族の一軒家（複数部屋・複数人・ペット）」の**複数部屋・複数人・ペット（飼い猫）**を実装した（人間は3人）。ユーザー指示「ステージ1より確実に難しく」「人間の新しいモデル」「さらに面白い攻撃」に対応。

## 内容

### 家（2部屋）
- ステージ1の台所に、**リビング**（x 7.24〜21.24、台所と同じ広さ）をつなげた。台所の勝手口は幅3の戸口になり、壁の両側と上の3枚に分割（登れる）。
- リビング: 脚の高いソファ（下に隠れられる・スリッパは届かない）、ローテーブルと格子柄のラグ、テレビ台とテレビ（青い光）、本棚（登れる・上に食料）、息子のおもちゃコーナー（おもちゃ箱・積み木・ボール・プレイマット・**虫かご**）、ゴミ箱、観葉植物、フロアランプ、カーテン付きの窓、天井灯。右の壁に廊下へのドア（家族の避難・業者の撤退先）。
- 人間用NavMesh（`Data/Stage02Navigation.asset`）と仲間の床グリッド（`Data/Stage02AllyGrid.asset`、114×48）を家全体で焼き直し。軍団モードの視点範囲も家全体に。
- 食料をリビングに9つ追加（ソファの下・テレビ台の上・本棚の上・ローテーブルの上など）、調査地点8つ、食料の補充地点5つ。

### 家族3人
| 人 | モデル | 攻撃 |
|---|---|---|
| 父 | ステージ1の住人 | スリッパ・罠・毒餌・スプレー（従来どおり）。最終防衛で駆除業者に変わる |
| 母 | **新規**（Blender）: お団子ヘア、からし色のニット、水玉のエプロン、ジーンズ、ピンクのスリッパ、右手にスリッパ、左手にコードレス掃除機 | スリッパ ＋ **掃除機** |
| 息子 | **新規**（Blender）: 赤い帽子、黄色のしま模様Tシャツ、半ズボン、スニーカー、左手に虫取り網。0.72倍の大きさ | **虫取り網**（スリッパは使わない）。足が速い（1.25倍） |

- モデル: `Tools/Blender/build_family_models.py`（住人と同じ19本の骨・同じ制作手順、各3段階LOD。母 約17,600三角形、息子 約14,100三角形）。編集元 `ArtSource/Blender/GokiTakeover_Family.blend`、プレビュー `family-front.png` など。Unity取込 `Editor/FamilyModelIntegration.cs`。
- **掃除機**（`VacuumAttack`）: 床にいるゴキブリを1.4〜5.2mで見つけると、ヘッドを向けて床に**橙の扇**（縁取り付き）で1.1秒予告 → 2.6秒吸い込み。扇の中はヘッドへ引き寄せられ、近いほど強い（1.3〜2.9/秒。歩き1.65・走り3.3）。横へ走れば扇から出られる。ヘッドまで吸われるとダメージ1、掃除機が詰まって止まる。仲間は吸われると戻らない（死体も残らない）。仲間は扇の横へ逃げる。
- **虫取り網**（`BugNetAttack`）: 3.1m以内で網を振り上げ、**橙の輪**（半径0.95、スリッパより大きい）に1.05秒後に振り下ろす。網の下の主人公は**捕まって動けない**: **Space を7回連打**で抜け出す。2.6秒で抜け出せないとダメージ1。網の下の仲間は**虫かご**へ（数に入らない）。**虫かごの前で E** を押すと全員出てきて主人公についてくる。仲間は振り上げから0.5秒遅れて気づいて逃げる。
- 家族も巡回（ランダム巡回・見失うと歩き回って探す）・仲間を狙う・区域にいると占領を止める・発見回数に数える。吹き出しはしゃべった人の頭上に出る。
- 最終防衛が始まると母と息子は掃除機・網をしまって廊下へ避難し、父が呼んだ駆除業者（父の姿が変わる）が残る。

### 画面
- 出撃前説明: 「MISSION ― STAGE 2」、家族ごとの危険（父のスリッパ・母の掃除機・息子の虫取り網…）、操作に「Space 連打 虫取り網から脱出」。
- プレイ中: 人間の欄は「母・掃除機！」「息子・虫取り網！」「父・巡回中」など最も危ない人を表示。警告「掃除機で狙われている！ 扇から横へ逃げろ」「掃除機に吸い込まれる！ 横へ走って逃げろ」「虫取り網が来る！ 橙の輪から逃げろ」「網に捕まった！ Space 連打で脱出 3 / 7」（進み具合のバー付き）。虫かごに仲間がいると「◇ 虫かご 仲間 2匹」、そばで「E 虫かごを開けて仲間を助ける」。軍団モードでは3人それぞれに名前と状態。
- ステージ選択: ステージ2は出撃可能に。危険の一覧も家族用。クリア画面「この家は俺たちのものだ！」・「飲食店」（制作中）を解放。
- 図鑑「人間」に母（吸引力の変わらないただ一人の母）と息子（夏休みの昆虫ハンター）を追加（回転台つき、初めて見つかった時に記録）。

## 追加（2026-10-25）: 飼い猫「ミケ」
- **モデル**: `Tools/Blender/build_cat_model.py`（新規）。三毛猫（白・茶・黒のまだら）、緑の目、赤い首輪と鈴。専用の骨格（背骨・首・頭・4本の脚各3本・しっぽ4本、計22本）、3段階LOD（約11,700三角形）。編集元 `ArtSource/Blender/GokiTakeover_Cat.blend`、プレビュー `cat-side.png` など。
- **動き**（`CatAnimator`、手続き的）: 対角の速歩、低く構えた忍び足としっぽの先のぴくぴく、飛びかかる前にお尻を振る、伸び切ったジャンプ、座って毛づくろい、丸まって昼寝（呼吸）。
- **行動**（`PetCat`）: ソファ横の寝床で昼寝 → 家の中をうろうろ → 疲れたら寝床へ。床を**動いている**ゴキブリ（主人公・仲間）が見えると興味がたまり、忍び寄る（「猫に見つかった！ 止まればやり過ごせる」）。2.8m以内で相手が動いていれば、**橙の輪**（半径0.95）で0.8秒予告してから飛びかかる。輪の中の主人公はダメージ1、仲間はスリッパと同じ（1回目はひっくり返る）。**止まっていると飛びかからず、興味をなくす。** 家具の下・壁・天井・家具の上・巣の中は見えない・届かない。寝ている時は1.8m以内で動くと目を覚ます。
- 猫専用の床グリッド（`Data/Stage02CatGrid.asset`、猫の大きさで判定）: ソファ・ローテーブルの下と巣（流し台下）には入れない。
- 最終防衛で家族と一緒に避難。リプレイで寝床に戻る。図鑑「人間」に「飼い猫ミケ」。効果音: 見つけた時の鳴き声・飛びかかる時の「シャー」（合成音）。HUD: 警告バナー、昼寝中は「Zzz」、軍団モードで「▲ 猫・忍び寄り」など。出撃前説明・ステージ選択の危険一覧に追加。
- テストで見つけて直した不具合: 停止中の主人公に飛びかかることがあった（飛びかかりは動いている時だけに統一）。人間のAIが止まっている間も古い状態のまま網・掃除機が発動していた（動作中の人間だけ攻撃するよう修正）。
- 検証: Edit Mode 62項目、ステージ2 Play Mode 51項目・Development Player 53項目（2回）、ステージ1 125項目（Play Mode・Player）、回帰 Phase 4 58・Phase 3 58・Blender 39・Phase 2 38 PASS。目視: [猫が忍び寄る](Validation/Phase5/stage2/player/stage2-cat-stalk-720p.png)・[飛びかかる予告](Validation/Phase5/stage2/player/stage2-cat-pounce-720p.png)。

- 4人目の家族（人間）は作っていない（家族3人＋猫）。
- 実際に通しで遊んでの難易度は未確認（自動テストは各攻撃・避難・クリアを個別に確認）。掃除機の強さ（`VacuumAttack` の PullNear/PullFar）、網の連打回数（`EscapePresses`）、各ゲージ目標（`Stage02_House.asset`）で調整できる。
- 母と息子の顔は住人の顔の形を元にしている（髪型・肌色・服で描き分け）。
- ステージ2のフレームレートは撮影時の表示のみで、ステージ1のような30秒計測は未実施。
- ステージ1の自動テストの「見失った後に歩き回る」は境界値（停止1.3秒）で1回失敗し、再実行2回ではPASS。人間が再発見して追跡に戻るタイミングによる揺らぎ。
