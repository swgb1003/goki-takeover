# UI 案2b（紙テープと段ボール）への作り替え

元のキャンバス: https://claude.ai/artifact/HP9Wfc1mUSofxBCrmMQEwK （ユーザーが選んだ「案2b」）。
このフォルダはその写しで、クラウドセッションからも読めるように置いている。

## ファイル
- `案/*.dc.html` … キャンバスの画面案（1280×720、インライン style の HTML）。`/_blob/…` の画像はここには無い（背景写真・人間の写真）。
  - `Title.dc.html` タイトル（**実装済み**: Scripts/UI/TitleMenu.cs + PaperKit.cs）
  - `StageSelect.dc.html` ステージ選択（段ボールの壁、写真を画鋲で留める、レシート、メモ、丸シールの「出撃」）
  - `Briefing.dc.html` 出撃前説明（方眼の作戦ノート、人間の写真、付箋、キーのテープ、丸シール）
  - `HUD.dc.html` プレイ中HUD（なじませ版）。`HudBefore.dc.html` は今のHUDとその問題点
  - `Kit.dc.html` 全画面共通の素材・色・文字の役割
- `現状/*.png` … 今の画面（2026-10-26 の検証版プレイヤー、1280×720）。title*.png は作り替え後の実物で、完成形の手本。

## 共通ルール（Kit.dc.html より）
- 素材は役割ごとに1つ: レシート＝目標・記録 / ノートの切れ端＝人間のようす / 紙テープ＝ラベル・時間・ボタン / 橙のガムテープ＝危険の警告だけ / ペットボトルのフタ＝数 / 丸いシール＝いちばん大事な決定（1画面に1つ）。
- 色: 紙 #F4EFE4（タイトルでは #DCCFB4）・インク #2A211A・黄緑＝仲間と決定・橙＝危険・琥珀＝食料・水色＝恐怖・赤ペン＝選択中の丸と下線・段ボール。
- 選択中の印は赤ペンの丸（＋小さなゴキブリ）。画面全体の仕上げ（暖色・周辺減光・粒子）は PaperKit の Grade を使う。
- 文字の役割: 太い見出し・大きな数字・警告 / 手書きのメモ・名前（短い語だけ）/ 説明と操作は読みやすいゴシック。Unity では OS フォント（Yu Gothic）1種しか無いので、TitleMenu と同じく太さは二重描き・影で出す。

## 実装の約束
- 部品は PaperKit に足す（テクスチャはコードで描いてキャッシュ。インポートしたアセットは使わない）。
- HUD は IMGUI、1280×720 の仮想キャンバス。新しい文字は HudGlyphs.Phase5 に足す。
- Phase 2〜4 のHUD（PhaseOne〜FourHud, PolishedHud）は変えない。PhaseFiveHud はステージ1〜3共通。
- 文言・情報量・操作は今の画面と同じにする（見た目だけ変える）。案に無い画面（設定・図鑑・ポーズ・クリア・失敗・巣・ガイド）は Kit の役割に合わせて作る。
