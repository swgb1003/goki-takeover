# ステージ3「町中華」 仕様（2026-10-26 決定）

ステージ2「一軒家」をクリアすると出撃できる3つ目のステージ。仕様書 9.1 の「飲食店（大量の食料、営業時間、衛生対策）」を、ユーザーとの相談で以下のとおり決めた。**ステージ2より全項目で難しくする。**

## 1. 舞台: 2階建ての町中華
油・餃子・チャーハン。中華鍋の炎や油はね・熱湯が攻撃になる、ゴキブリにとっての楽園。

| 階 | 区画 | 中身 |
|---|---|---|
| 1F | 厨房 | 中華レンジ（コンロ）・中華鍋・寸胴・フライヤー・作業台（脚が高く下に隠れられる）・業務用冷蔵庫 |
| 1F | 洗い場 | 二槽シンク・食洗機・残飯バケツ・食器棚・裏口。**巣はシンク下のグリストラップのそば** |
| 1F | 客席 | カウンター席（厨房との間に配膳口）・テーブル席・レジ・入口・2Fへの階段 |
| 1F | 食品庫 | 米袋・小麦粉袋・段ボール・棚・**ウォークイン冷蔵庫** |
| 2F | 宴会座敷 | 畳・座卓（下に隠れられる）・座布団・床の間・宴会の大皿 |
| 2F | 休憩室・事務所 | ロッカー・まかないの机・仮眠用ソファ・事務机 |

- 階の移動: 人間は**階段**。ゴキブリは階段のほか**料理用リフト**（15秒ごとに1F厨房⇔2F座敷を往復）と**換気ダクト**（厨房⇔2F休憩室、ゴキブリ専用。入口は壁の下の金網で、仲間も通れる）。
- 実装メモ: 2Fは1Fの真上ではなく、同じ高さ（床 y=0）の離れた場所に作り、階段・リフト・ダクトでは短い暗転で移動する。既存の「床の上にいるか」の判定・仲間の床グリッド・人間のNavMeshをそのまま使え、不具合が出にくいため。見た目は2階建て（階段は上へ登り、2Fの階段は下りている）。

## 2. 人間
| 人 | 攻撃（すべて橙の予告つき） |
|---|---|
| 店主（料理長） | お玉で叩く（スリッパと同じ扱い）＋**熱湯流し**（床に橙の帯 → 熱湯が帯の形に流れる） |
| おかみさん（接客） | **お盆で叩く**（横長の四角）＋**アルコールスプレー**（扇形、当たると数秒遅くなる） |
| バイト（洗い場・掃除） | **モップがけ**（濡れた床が残り、滑って止まれない）＋**デッキブラシ**（押し流す） |
| 客（営業中に1〜6人） | 攻撃しない。見つけると悲鳴（恐怖＋8＝普通の発見の約3倍）、近くの店員が駆けつける。驚いた客は料理を残して帰る（食べ残し） |
| 保健所の検査員 | 途中のイベント。懐中電灯で家具の下まで照らす |
| 最終防衛 | 臨時休業。**駆除業者が2人**来て、1F→2Fの順に全館を燻煙 |

- 人間以外の敵（猫・ネズミなど）は入れない。
- **登場する人間は全員、新しくBlenderで作る**（ユーザー指示 2026-10-26。ステージ1・2のモデルは使わない）。
  - 店主: 白い調理服・和帽子・前掛け・右手にお玉
  - おかみさん: 三角巾・割烹着・右手にお盆、腰にアルコールスプレー
  - バイト: キャップ・Tシャツ・ゴム長靴・モップ／デッキブラシ
  - 客: 3種類（サラリーマン・学生・おばあさん）
  - 保健所の検査員: 白衣・マスク・クリップボード・懐中電灯
  - 駆除業者2人: ステージ1の業者とは別の新しい作業服（2人で色違い）

## 3. ギミック
1. **営業時間のサイクル（1周 約7分）**
   | 時間帯 | 長さ | 中身 |
   |---|---|---|
   | 仕込み | 60秒 | 店主とバイトが厨房。作業台に餃子が並ぶ |
   | ランチ | 120秒 | 客3〜6人。店員は忙しく視野×0.6。食べ残しが出る |
   | 中休み | 60秒 | バイトのモップがけ。罠を2つ補充 |
   | ディナー | 120秒 | 客2〜5人。2F宴会座敷も使い、焼売のせいろが出る |
   | 閉店 | 60秒 | 消灯。店主が懐中電灯で見回るだけ。閉店ごとに業務用の罠（ゲル状の毒餌・粘着マット）が増える |
2. **熱い場所**: 営業中のコンロ・フライヤー・鉄板は乗るとダメージ（陽炎と橙の縁で表示）。
3. **料理用リフト**: 1F厨房⇔2F座敷を15秒ごとに往復。食料を持ったまま乗れる。
4. **換気ダクト**: ゴキブリ専用の抜け道（入口は金網）。
5. **ウォークイン冷蔵庫**: 扉が開いている間だけ入れる。中は寒く動きが遅くなる（長くいるとダメージ）。高い食材がある。
6. **大物運び（新システム）**: 焼売のせいろ（値5）は仲間3匹がそろうと動く。速さは歩きの0.6倍。途中で1匹やられるとその場に落とす。
7. **保健所の検査員**: 2周目のランチの前に1回（約90秒）。懐中電灯で家具の下まで照らし、照らされると発見扱い。検査中に一度も見つからなければ恐怖＋20、見つかれば店が「警戒」に。
